Run the creative sprint.

Everything you need is in this repo, in sprint/ and in the account's brand
kit. Do not ask me for paths, counts, or confirmations that you can work out
yourself. Work autonomously until you hit the one stop below.

INPUTS
  sprint/briefs/    the briefs file from Metrix. Render one asset per brief,
                    however many there are. The count is not a rule.
  sprint/refs/      reference images. Upload them all, use the returned URLs
                    as the model's image input. Without them the model invents
                    the product.
  the runs folder   everything you produce goes here. It is the runs folder
                    the session start names: sprint/out/, unless the plugin's
                    runs folder option names another.
  the brand kit     the account's brand-kit.json, and its
                    MASTER_EXECUTION_PROMPT.md when it has one. Kits are kept
                    outside this repository, in the assets folder's
                    brand-kits/ (the session start names the assets folder).
                    Ask me where it is if it is not there, in sprint/, or
                    named in the briefs.

DO THIS, IN ORDER, WITHOUT ASKING
  0. Load the metrix-produce skill (metrix-creative-engine:metrix-produce).
     It routes each brief by its declared format and names the skill for
     each step. The steps below are this sprint's order and its one stop;
     where the two differ, this file wins.
  1. Read the brand kit. Its client_account_rules and conflicts_to_resolve
     override the briefs, and its rules override this file.
  2. If the kit has a MASTER_EXECUTION_PROMPT.md, read it and follow it.
  3. Upload every file in sprint/refs/ and keep the URLs.
  4. Run kie_validate_brief on every brief.
  5. Check credits. Tell me the number and the estimated spend in one line.
  6. Render TWO cells from different rows. Download them to the runs folder.
     Show them to me.

  --> THIS IS THE ONLY STOP. Wait for my yes.

  7. On yes: render the rest. One model for the whole batch, with the aspect
     ratio set explicitly as a parameter. Download every asset to the runs
     folder with its MST name as you go, never at the end.
  8. Report: one table, one row per brief. Cell, pass/fail on the five
     alignment rows, credits, filename. Then the total spent and anything you
     could not make pass.

RULES THAT ARE NOT NEGOTIABLE
  - The hook and the CTA go IN the image, quoted verbatim from
    copy_architecture.
  - No invented reviews, ratings or counts.
  - Read every character of rendered text before accepting an asset.

IF SOMETHING IS WRONG
  Fix it and tell me in the report. Do not stop to ask unless it is the
  matrix isolation check failing, or you would have to spend credits on
  something I did not authorise.
