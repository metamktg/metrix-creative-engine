## Craftsman Response to Artisan

**Their position:** Compile the look into a checked `mce.look/1` contract that drives one Chrome renderer for every format, and gate the rendered output itself (WCAG contrast against the worst pixel under each text box, transition parity with a declared `transitions[]`, look-token parity, carousel seams within 1 px, SFX bound to the transition or text slam it accents), using an anonymous sample kit and real fonts.

**My response:** Modify

**Reasoning:** Artisan is right that these gates measure what the viewer sees, and right that my Round 1 golden run would let them pass trivially: a flat `color=c=gray` clip has one luminance value, so a contrast check over it proves nothing, and a hard-cut-only synthetic run never asks QA to tell a declared crossfade from a bad blend. But the fix is not real Kie frames in CI; it is putting each gate's proof at the right layer of the pyramid. The repo already shows how. `src/__tests__/qa-video-exempt.test.ts:92` builds a deliberate double exposure from two lavfi sources (`testsrc2` blended into `testsrc` over frames 40-50) and asserts it FAILs unexempted and reports EXEMPT only when an exemption covers the whole event. That is a hand-made adversarial fixture, it is deterministic, it takes about a second at 160x288, and it is the pattern every Artisan gate should copy. So the rule I propose: **no gate merges without a known-bad and a known-good fixture pair at the contract layer**, generated by ffmpeg lavfi in the test, small frames, no Chrome where the gate does not need it. Contrast: a `testsrc2`/gradient background with a bright band under the caption box and white text FAILs below 4.5:1; the same frame with the `surface.plate` token PASSes; a test also proves the 95th-percentile sampler picks the bright band, not the mean. Transition parity: the same blend graph as the exempt test, run once with a declared `fade` window over frames 40-50 (PASS, that window exempt from `transitions.at_cuts`) and once undeclared or one frame wider than declared (FAIL). SFX drift: sine clicks placed at the cut, at +1 frame and at +3 frames against the `onsetGuard` lead, with the expected PASS/PASS/FAIL. Carousel seams: two rendered cards with the continuity element offset 0 px and 2 px. The golden run per format then does a different job: it proves the gates are **wired and fed** (look.json hashed into the manifest, every gate ran and emitted a measured value, the review record cites the qa hash), not that they catch defects. To stop the golden run from being trivially green, its stub serves textured lavfi media (`testsrc2`, `mandelbrot`, `gradients`) rather than flat colour, and a fixture-sufficiency assertion requires luminance variance under each text box above a floor, so a future flat fixture fails the test instead of silently weakening the gate. Fonts are already solved for CI: `src/__tests__/fixtures/fonts/Geist-Regular.ttf` with its OFL licence is committed, so the font-resolution and health check are tested against an OFL face, and licensed client faces load only in private runs from the run dir, never in CI. The anonymous sample kit becomes the committed `look compile` fixture; `brand-kits/eastcoastartstudio/` (four git-tracked files today) moves out of the tracked tree to the run dir, as Artisan found. The one gap synthetic media cannot close is the statistics of real model frames (skin, specular product shots, busy backgrounds) under a caption; for that I would accept a small replay corpus: 3-5 frames generated once from anonymous fixture prompts, paid once, committed with their sha256 and ledger entry, and replayed by the stub forever, so CI stays zero-spend and deterministic. Budget: contrast sampling reuses the frames and `__layout` boxes `--mode check` already captures, gate fixtures run at 160x288, and only the golden run renders at full size, one per format, in parallel; that keeps Artisan's gates inside `npm run verify` without a second Chrome pass per gate.
